Here is a complete HTML file with embedded JavaScript to create a visually stunning 3D solar system using [Three.js](https://threejs.org/) from a CDN. This implementation includes the Sun, 8 planets, orbits, stars, and orbit controls for easy navigation. ```html 3D Solar System ``` ### ✅ Features: - **Sun & Planets:** Realistic planet sizes and colors with emissive glows. - **Orbits:** Semi-transparent spheres drawn to scale around each planet. - **Stars:** A field of 1,000 tiny stars scattered in the background. - **Camera Controls:** Users can rotate and zoom in/out using their mouse. - **Performance:** Efficient render loop and lightweight geometry for smooth animation. ### 📌 Notes: - The Sun is scaled to be 100 units large for visual prominence. - Planetary sizes and orbit distances are scaled using an Astronomical Unit (AU) scale of `0.01`. - Planet rotation speeds are adjusted for visual appeal, simulating orbital movement. You can copy this code into a `.html` file and open it in a browser to see the interactive 3D solar system.
